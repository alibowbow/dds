최소침습 발치의 기본 생역학

  1. 치은과 supracrestal fiber 분리 — 치경부를 원주 방향으로 확인하고 연조직 열상과 치조정 손상을 방지.
  2. PDL 공간 확보 — 접근 가능한 line angle부터 치근 장축과 평행하게 작은 깊이 증가. 협측판·인접치를 지렛점으로 사용하지 않음.
  3. 치근 형태에 맞는 운동 — 원추형 단근은 제한적 회전, 편평·만곡·다근치는 협설 방향과 분할을 사용. 저항의 방향을 해부학과 대조.
  4. 치근단 파지 — 겸자를 가능한 치근단 쪽에 적합시키고 미끄러짐·치관 분쇄를 줄임. 과도한 압착보다 지속적이고 통제된 힘.
  5. 조기 분할 — 다근치와 이개치근은 단근 단위로 바꾸어 제거 경로를 단순화. 치간골·협측판을 희생해 한 덩어리로 제거하지 않음.
  6. 진전 기반 전환 — 충분한 PDL 분리 후에도 동요도 증가가 없으면 힘을 키우지 않고 영상·시야·분할·골삭제 계획을 변경.
공기배출식 turbine 주의 — 피판 또는 연조직 아래에서 압축공기가 유입되면 피하기종과 종격동기종이 발생할 수 있습니다. 외과용 전기 handpiece와 충분한 주수·흡인을 사용합니다.

  • Luxator LX 사용 시 내부 water·spray는 끄고, 기기 세척·윤활·멸균은 구형 IFU 적용

근관 또는 치근 중앙에 self-tapping screw를 고정하고 지지대·cable·traction head로 힘을 치근 장축에 전달하는 방식입니다. Benex, Easy X-Trac 등 제품은 구성과 drill·screw 규격이 다르므로 서로의 수치를 대입하지 않습니다.

적합직선형 단근·잔존치근, 중앙 장축 천공과 나사 유지가 가능한 견고한 치질, 안정적인 평면 지지 확보

제품별 workflow — 아래 순서는 Benex-Control IFU의 예입니다. Easy X-Trac은 3개 drill의 순차 사용, self-cutting screw와 좌·우 protector plate를 사용하는 별도 방식이므로 Benex의 7mm·30초·30–40초 수치를 적용하지 않습니다.
  1. PDL 사전 분리 — 원주 방향 섬유를 먼저 절단. 강하고 긴 치근은 근심·원심에서 가는 lever/Twister로 약 30초간 장축성 luxation을 시행하고 횡방향 운동은 피함.
  2. 다근치 완전 분할 — 각 치근을 독립된 단근 단위로 만든 뒤 이동 여부 확인.
  3. Pilot hole — Benex-Control 제조사 IFU는 치근 중앙의 견고한 경조직에 약 7mm 깊이의 축방향 삽입공을 제시. 충분한 냉각과 간헐적 상하 운동을 적용하며 실제 bur·속도는 해당 IFU 적용.
  4. Screw 고정 — 적합한 직경을 선택해 유지력을 확인. 우식·근관충전재·얇은 잔존벽을 나사 유지부로 사용하지 않음.
  5. 지지대와 축 정렬 — 평평하고 치근 장축에 직각인 지지면 확보. 불균일 지지면·free-end·무치악·인접 크라운이 있으면 quadrant support로 하중을 분산하고 screw와 cable의 축을 일치.
  6. 점진적 견인 — hand screw를 천천히 조여 지속 장력 적용. 강하고 긴 치근은 최대하 장력을 30–40초 유지한 뒤 조금 더 조이고 같은 과정을 반복.

Easy X-Trac 제조사 술식 구성
  1. 접근 확보 — 치관을 필요한 만큼 낮추고 치근 중앙의 직선 접근 확인.
  2. 순차 천공 — 제조사 제품자료는 1.1→1.3→1.5mm 전용 drill을 8,000–10,000rpm에서 순차 사용하도록 제시.
  3. Screw 선택 — 치근 길이에 맞는 self-cutting screw를 수동으로 시작한 뒤 ratchet으로 고정.
  4. Protector plate — 좌·우 plate에 silicone을 적용해 인접치의 금속 노출을 없애고 screw와 plate를 약 90°로 정렬.
  5. 축방향 견인 — extractor jaw가 screw head를 완전히 감싸도록 연결하고 손잡이 screw를 천천히 열어 견인.

위 수치는 Easy X-Trac 현행 제조사 제품·술식 페이지에 제시된 값이며 정식 독립 비교지침이 아닙니다. 나사는 변형되는 1회용 부품으로 안내됩니다.

Benex-Control 기기 제한 — 제조사 IFU는 치아 유착·골절뿐 아니라 두경부 방사선/항암치료와 일부 급성 혈관·조혈계 질환도 기기 사용 금기로 기재합니다. 이는 Benex-Control 기기의 제한이며 모든 발치의 일반 금기로 확대하지 않습니다. 실제 사용 전 현행 지역 IFU를 확인합니다.

맹목적 탐색 중단 — 치근이 상악동, 설하·악하·익돌하악·측두하 공간 방향으로 이동해 완전히 보이지 않으면 추가 조작을 멈추고 영상과 구강악안면외과 의뢰를 시행합니다.
